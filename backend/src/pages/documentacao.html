2. DESCRIÇÃO GERAL DO PRODUTO

2.1. Usuários e sistemas relacionados

O sistema irá envolver os seguintes stakeholders: Líder de produção, setor administrativo e gestores. O sistema permitirá o cadastro e acompanhamento de ordens de produção.

2.1.1. Descrição dos Stakeholders

Número Identificador Ator Definição
1 Usuário Pessoa autorizada a usar o sistema com funções não gerenciais.
2 Funcionário Líder de produção e setor administrativo que utilizam o sistema para cadastrar, atualizar e acompanhar as ordens.
3 Administrador Responsável pelo controle geral do sistema, com acesso total.
4 Manutenção Profissionais responsáveis pela manutenção e atualizações do sistema.
5 Gestor Responsável por acompanhar resultados e analisar dados.

2.2. Regras de Negócio

O sistema deve permitir o cadastro de ordens de produção, com status como “Aguardando Produção”, “Em Produção” e “Finalizado”. Acesso restrito apenas para usuários autorizados.

2.4. Histórias de Usuário

  • Como líder de produção, quero cadastrar uma ordem de produção para registrar novos pedidos.
  • Como setor administrativo, quero visualizar todas as ordens e filtrá-las por status.
